# Student Data Management System

A web-based application designed to manage and analyze student academic records, including attendance and coursework marks. Built using Python and Flask, it provides functionalities for data visualization and filtering based on specific criteria.

## Features

- Upload and process student data from Excel files.
- Filter students based on:
  - Attendance percentage (e.g., 0% to 50%).
  - Coursework marks (e.g., 5 to 10).
- Generate and download filtered datasets.
- User-friendly interface with HTML and CSS front-end.

## Technologies Used

- **Backend**: Python, Flask
- **Frontend**: HTML, CSS
- **Data Processing**: pandas, openpyxl
